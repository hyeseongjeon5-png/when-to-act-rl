## 2. 결론 (다음 세션에서 이걸 전제로 시작한다)

| 환경 | 임계 비용 λ\* (세 계열 모두) | 판단 |
|---|---|---|
| MountainCar-v0 (희소 보상) | **0** — λ=0에서도 규칙을 못 이김 | 규칙을 쓰라 |
| LunarLander-v3 (조밀 보상) | **2.0** | 학습을 쓰라 |

**답은 비용 λ 하나가 아니라 '보상이 조밀한가'와 '이미 좋은 규칙이 있는가'에 먼저 달려 있다.**

부수 결론 3가지:
- Lazy-MDP가 두 환경 모두 최강 — 기본 규칙에 위임할 수 있어 밑바닥이 있다
- 비용이 오르면 학습은 실제로 행동을 아낀다 (LunarLander DQN 340.8회 → 63.4회, 81% 감소)
- TempoRL은 탐험이 병목인 환경(MountainCar)에서만 표준 DQN보다 낫다

숫자는 전부 `results/aggregate/*_iqm.csv`, `*_lambda_star.json`에서만 인용할 것.

## 4. 중요 — 학습된 모델은 남아 있지 않다

`src/train/train_agent.py`는 조건이 완료되면 **체크포인트를 지운다**(디스크 절약, 의도된 동작).
510조건이 전부 완료 상태이므로 "이어서 학습할 것"은 없고, 새 실험은 처음부터 학습한다.

- 남아 있는 것: 조건별 평가 결과(`results/raw/`, 22MB), 집계(`results/aggregate/`), 그림, 보고서
- 남아 있지 않은 것: 신경망 가중치(.pt)
- 모델을 남기고 싶으면 `train_agent.py`의 `p["ckpt"].unlink()` 부분을 조건부로 바꿀 것
  (270조건 × 약 5MB ≈ 1.4GB — .gitignore에 이미 제외돼 있다)

## 5. 다음에 할 일 (우선순위 순)

### (1) 논문 1·2·5장 — 가장 급함, 기계 시간 0
- `paper/03_방법.md`, `paper/04_결과.md`는 있다. **4장은 자동 생성이므로 손으로 고치지 말 것**
  (`python -m src.report.make_results_chapter` 로 다시 만든다)
- 없는 것: 1장 서론, 2장 배경/선행연구, **5장 논의**
- 5장에 쓸 재료는 이미 다 있다: 두 환경의 대조, 얼어붙은 퇴화 균형점, Lazy-MDP의 밑바닥 구조,
  TempoRL의 순위 역전, 탐험 도달률 측정표

### (2) MinAtar 확장 (계획서 일정: 9~10월)
- `src/envs/cost_wrapper.py`의 `NOOP_BY_ENV`에 MinAtar 게임별 no-op 행동 번호를 등록해야 한다
  (현재 미등록 상태라 래퍼가 거부한다 — 게임별로 확인 필요)
- 관측이 (10,10,4) 3차원이라 `mlp()` 대신 CNN이 필요하거나 평탄화가 필요하다
- 예상 규모: 파일럿으로 조건당 단가부터 재고 λ 격자를 정할 것

### (3) 비용 부과 방식 민감도 (계획서 일정: 9~10월)
- 지금은 **매 스텝 부과**(작동 비용). 대안은 **결정 시점 1회 부과**(전환 비용)
- 후자는 TempoRL에만 유리해지므로 공정 비교가 깨진다 — 별도 축으로 보고할 것
- 구현은 `ActionCostWrapper`에 모드 플래그 하나 추가하면 된다

### (4) 격자 세밀화 (선택)
- MountainCar λ\*가 0~0.01 사이에 있는지 확인하려면 λ=0.002, 0.005 추가
- LunarLander는 λ=1.37~2.0 사이가 비어 있다 (1.6, 1.8 추가하면 λ\* 해상도가 올라간다)
- 격자 추가는 설정 지문을 바꾸지 않으므로 **기존 결과를 그대로 두고 새 λ만 돌면 된다**

## 7. 이번 스프린트에서 얻은 규칙 (다음에도 지킬 것)

1. **최종 점수는 스냅샷 3장 평균으로 낸다.** 한 시점만 재면 정책 진동 때문에 동전 던지기가 된다
2. **설정 지문을 붙인다.** 설정이 바뀌면 예전 체크포인트·결과가 조용히 섞인다
3. **시드 1개 결과를 앞세우지 않는다.** 시드0에서 TempoRL이 최고였지만 시드 10개로는 반대였다
4. **완료 감지는 상태 파일(progress.json의 finished)로 한다.** 로그 파일 경로에 의존하면 놓친다
   (이번에 MountainCar 완주를 30시간 인지 못 했다)
5. **논문 표는 집계 파일에서 자동 생성한다.** 손으로 옮기면 틀리고, 갱신하면 원고가 낡는다
6. **공개 코드는 받아서 대조한다.** 논문 본문만 읽었으면 예산이 10배 부족한 걸 몰랐을 것이다
