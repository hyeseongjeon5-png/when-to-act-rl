# 실험 설계 v1 (2026-08-24)

결론 먼저: **"기준선 먼저, 파일럿 먼저, 본실험은 마지막"** 순서로 간다. 아래 표의 빈칸(확인 필요)은 파일럿에서 정한다.

## 1. 환경과 비용 래퍼

| 환경 | 행동 공간 | 무행동(no-op) | 비고 |
|---|---|---|---|
| MountainCar-v0 | 3 (좌/무/우) | action 1 | 가장 가벼움 — 파일럿용 1순위 |
| LunarLander-v2 | 4 (무/좌/주/우 엔진) | action 0 | v2가 없으면 v3 사용하고 기록 남기기. Windows는 `pip install swig` 먼저 |
| MinAtar (breakout 등 1~2개) | 게임별 | 게임별 확인 필요 | 시간 남으면. 게임 선정은 파일럿 후 결정 |

- 비용 규칙: `r' = r − λ·1[행동 실행]` — **무행동이 아닌 행동을 실제 실행한 스텝에만** λ를 뺀다 (`src/envs/cost_wrapper.py`)
- TempoRL처럼 행동을 k스텝 유지하는 경우: **새 행동을 "결정"한 시점에 1번만 부과할지, 유지되는 매 스텝 부과할지**는 연구 질문에 직결 → 기본은 "결정 시점 1번 부과"(전환 비용 해석), 민감도 확인용으로 매 스텝 부과도 파일럿에서 1회 비교. 어느 쪽이든 논문에 정의를 명시
- 평가 시 원래 보상 r과 비용 차감 보상 r' , 행동 횟수를 **모두 따로 기록**한다

## 2. 비교 대상 (4계열)

| 계열 | 내용 | 구현 출처 |
|---|---|---|
| (가) 표준 DQN | 매 스텝 행동 선택 | 직접 구현 (수업 실습 기반) |
| (나) TempoRL 방식 | 행동 + 지속 길이 j를 함께 학습 | automl/TempoRL 공개 코드 기준 재구현 |
| (다) Lazy-MDP 방식 | 기본 정책(무행동/규칙)에 위임, 개입 여부 학습 | 논문 정의 기준 직접 구현 |
| (라) 고정 규칙 | k스텝 주기 행동(k∈{1,2,4,8}), 임계값 규칙(환경별 정의), 무행동 | `src/baselines/fixed_rules.py` |

- 임계값 규칙 정의(초안): MountainCar — 속도 부호 방향으로 가속(에너지 펌핑 규칙). LunarLander — 각도·속도 임계값 초과 시에만 엔진. 파일럿에서 확정 후 논문에 수식으로 명시
- (라)는 학습이 없으므로 시드는 환경 시드만 적용

## 3. 실험 축

- λ 격자(초안): `0, 0.01, 0.03, 0.1, 0.3, 1.0` × 환경별 보상 스케일 보정 — **파일럿에서 "λ=0이면 표준과 동일, 최대 λ면 무행동이 최적"이 되도록 양 끝을 맞춘 뒤 확정**
- 시드: 학습 시드 10개 이상 (`0~9`), 평가는 시드당 100 에피소드(탐험 끔)
- 예산: 환경별 동일 학습 스텝 수 고정 (파일럿에서 DQN이 λ=0에서 수렴하는 규모로 결정, MountainCar 기준 확인 필요)

## 4. 기록 항목 (조건 = 환경 × 에이전트 × λ × 시드)

총보상(r 기준·r' 기준), 에피소드당 행동 횟수, 학습 곡선(평가 시점별), 규칙 기준선 대비 승률, 학습 시간

저장 형식: `results/raw/{env}/{agent}/lam{λ}/seed{n}.csv` + 실행 config 사본 (`rl-experiment-protocol` 스킬 참조)

## 5. 분석 (본실험 후)

- IQM + 95% 계층 부트스트랩 신뢰구간, `rliable` 사용 (`rliable-reporting` 스킬)
- **λ-성능 지도**: x=λ, y=IQM 총보상(r' 기준), 에이전트별 곡선 + CI 밴드 + 최고 고정 규칙 곡선
- **임계 비용 λ\***: 학습 에이전트의 CI 하한이 최고 고정 규칙의 CI 상한 아래로 내려가기 시작하는 λ (교차 판정 기준을 논문에 명시)
- 규칙이 이기는 영역에서 원인 분석: 상태 관측의 정보량, 최적 행동의 단순성, 비용 대비 보상 스케일 등 가설별 검토

## 6. 위험 요소와 대비

| 위험 | 대비 |
|---|---|
| LunarLander box2d 설치 실패(Windows) | swig 선설치, 안 되면 MountainCar+MinAtar로 진행하고 기록 |
| TempoRL 재현 안 됨 | 공개 코드의 grid world/MountainCar 예제부터 그대로 돌려 수치 대조 |
| 본실험 시간 폭발 | 파일럿으로 1조건 소요시간 측정 → 총시간 = 조건 수 × 단가 계산 후 λ 격자·환경 수 조정 |
| Acrobot 미수렴 경험 재발 | 수렴 확인된 하이퍼파라미터(공개 코드 기본값)에서 출발, 튜닝 최소화 |
